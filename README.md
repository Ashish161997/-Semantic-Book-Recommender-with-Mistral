# 📚 Semantic Book Recommender with Mistral 

This Kaggle notebook contains the complete code for the freeCodeCamp course,  
**"Build a Semantic Book Recommender with LLMs "**, using the **Mistral** model.

The project includes the following five key components:

---

### 🧹 1. Text Data Cleaning  
- ✨ **Purpose:** Preprocesses and cleans the book dataset to prepare it for vectorization and modeling.

---

### 🧠 2. Semantic (Vector) Search & Vector Database  
- 🔍 **Purpose:** Builds a vector database using text embeddings to enable natural language book search.  
- 💡 **Example Query:** *"a book about a person seeking revenge"*  
- ✅ **Outcome:** Returns the most semantically similar books.

---

### 🏷️ 3. Zero-Shot Text Classification with Mistral  
- 🧾 **Purpose:** Uses zero-shot classification to label books as *fiction* or *non-fiction*.  
- 🔧 **Use Case:** Allows users to filter recommendations by genre.

---

### 🎭 4. Sentiment & Emotion Analysis  
- 💬 **Purpose:** Extracts emotional tones (e.g., suspenseful, joyful, sad) from book descriptions using Mistral.  
- 🎯 **Use Case:** Lets users sort and discover books by emotional tone or mood.

---

### 💻 5. Gradio Web App Interface  
- 🌐 **Purpose:** A user-friendly web app built with Gradio to get interactive book recommendations.  
- 🚀 **Functionality:** Users can input a natural language query and receive personalized results with filtering options.

---

> 📌 **Note:** All components are implemented in a **Kaggle notebook** for a seamless, end-to-end experience.
